# The Rise of the Jackson 5: 2D animated music story

A 69.2-second, 9:16, 1080×1920, 60 fps animated short, cut to "I Want You Back". Everything is generated by code in `src/`. The pipeline is: audio analysis → section selection → character rigs → beat-locked choreography → five scenes → render → encode.

## Outputs (`output/`)

| File | Notes |
|---|---|
| `FINAL_JACKSON5_ANIMATION.mp4` | H.264 High, 1080×1920, 60 fps, AAC 320k. **Not committed to git**, because it contains the copyrighted recording. |
| `FINAL_JACKSON5_SILENT.mp4` | Clean picture-only master, for replacing or licensing the audio separately. |
| `AUDIO_BEAT_MAP.json` | Tempo, every beat/downbeat, onsets (bass/snare), energy, structure, the scored section candidates, the edit window and a timecoded music → visual cue sheet. |
| `model_sheet_{home,club,studio,tv,arena}.png` | Character line-up, front / 3/4 / back turnaround and expressions, for each era's wardrobe. |

## Rebuild

```bash
apt-get install ffmpeg fonts-league-spartan fonts-ebgaramond fonts-bebas-neue
pip install skia-python librosa numpy scipy
cp "<your copy of the song>.mp3" audio/source.mp3
cd src
python3 analyze_audio.py && python3 select_section.py   # analysis + candidate scoring -> build/
python3 beatmap.py                                      # output/AUDIO_BEAT_MAP.json
python3 render.py stills 2 9.3 26 41.5 62               # QA contact sheet -> build/stills.png
python3 render.py test 8 18                             # 10 s test clip with audio
python3 render.py final                                 # full film, ~10 min on 4 cores
```

## How it works

- **Music:** the beat tracker finds ≈99.4 BPM. The beats are smoothed with a local linear fit, which keeps the live band's real tempo drift but removes analysis jitter. Every move and cut is placed on *tracked* beats (`timing.py`).
- **Selected section:** song 0.50–68.48 s, plus a 1.22 s fade. It was chosen over five other scored windows; `select_section.py` holds the scoring and the JSON records the comparison.
- **Characters** (`character.py`): five parametric designs. Each has its own height, head size, face shape, afro shape, eye spacing, brows, skin tone and signature color, and the designs stay fixed across all eras. The renderer uses:
  - 2-bone IK legs
  - instrument-hand IK (Tito's guitar, Jermaine's bass)
  - cel shading with rim light and colored line work
  - expressive eyes with blinks and look direction
  - 5 mouth shapes and 5 hand shapes
  - follow-through on hair and vest fringe
  - a spin cheat with back view and smear frames
- **Choreography** (`choreo.py`): groove bounce, step-touch with claps, point hits with anticipation and overshoot, spins, arm rolls, shimmy, slides, kicks, knee drop and mic singing. Each brother runs with a slight ripple delay. Lip movement follows the vocal-band envelope of the recording.
- **Scenes:**
  1. Gary at dusk → through the window → living-room rehearsal (orbit move)
  2. Brick-wall amateur night → spotlight → curtain transformation → grand theater
  3. Vinyl drop → studio (VU meters driven by the audio) → close-up → producers → gold-record explosion
  4. TV stage: op-art, tracking slide, silhouette sequence, close-up and spin
  5. Match cut on Michael's face → arena pull-back, crowd, final golden pose, title
- **Look:** per-scene palette and grade, parallax layers, film grain, vignette, volumetric beams, particles.

## Limitations (honest)

- This is procedural vector animation, not hand-drawn frame-by-frame work. The characters are appealing and consistent, but body turns are 2.5D cheats, and full profile views are not used.
- Dance moves come from a pose library, so the choreography is musical and clean but simpler than real Jackson 5 routines.
- Lip-sync follows the vocal *energy*, not phonemes.
- Likenesses are stylized tributes, not portraits.
- The song is copyrighted. Publishing the version with audio needs a license, or must happen on a platform that licenses the music (e.g. TikTok's or YouTube's music library). The silent master is provided for exactly that.
